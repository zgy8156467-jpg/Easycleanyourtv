# 远程协助指南

电视上装不了向日葵，能用的是 ADB。对方开 ADB、把电视接进虚拟局域网，我们这边就能连上去看屏、操作、装包、抓日志。

## 群公告（直接复制发群）

> **装坏了、开不了机、Home 不回桌面？可以远程帮你看。**
>
> 需要你做三步：
> ① 电视设置里打开「ADB 调试」（设置 → 账号与安全 → ADB 调试）
> ② 电视上装一个 ZeroTier，加入我们的网络（网络 ID 私聊发你）
> ③ 把电视在 ZeroTier 里的 IP 发我
>
> 处理完请把「无线调试」关掉。
>
> 注意：远程期间我能完全操作你的电视，所以只在我处理的时候开着，处理完立刻关。不放心的话，全程可以自己盯着屏幕。

## 群友操作步骤

### 1. 打开 ADB 调试

设置 → 账号与安全 → ADB 调试 → 打开。

小米电视第一次打开会要确认，有的固件要连按「产品型号」五次才出现开发者选项。

### 2. 装 ZeroTier

- 下载 ZeroTier 的 Android APK（电视上用 ZerotierFix 这个改版更好操作），拷到 U 盘，用电视的媒体中心安装。
- 打开装好的客户端，点右上角加号，输入网络 ID，确认加入。
- 回到列表会显示一个 `172.x.x.x` 之类的地址，把这个地址发过来。

电视上的 ZeroTier 用遥控器操作：上下选，确定键点。

装不上或连不上，退一步用蒲公英组网，步骤一样，把蒲公英给的虚拟 IP 发过来。
少数电视固件禁止安装这类组网应用，遇到就换蒲公英，或者让对方家里有 OpenWrt 路由器的直接在路由器上组网，电视不用装。

### 3. 保持电视开机、联网

不用插 U 盘，不用开着我们的 app。处理完我会说一声，你再：

- 关掉「ADB 调试」；
- 在 ZeroTier 里离开网络，或者直接卸载 ZeroTier。

## 我们这边的操作清单

### 连之前问清楚

- 机型、系统版本（设置 → 关于），或者让电视先装我们的包，反馈里会自动带。
- 现象：启动崩溃 / Home 不回桌面 / 装不上 / 原厂桌面抢回来。
- 是否愿意让我们装包、改无障碍、改使用情况权限。
- 有没有重要设置（壁纸、收藏的 App），处理时尽量不动。

### 连上先看

```bash
adb connect <电视IP>:5555
adb devices
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
adb shell dumpsys package com.gathin.tvhome | grep -E "versionName|versionCode"
adb exec-out screencap -p > /tmp/tv.png
```

看当前 Home 是谁：

```bash
adb shell cmd package resolve-activity --brief \
  -a android.intent.action.MAIN -c android.intent.category.HOME
```

### 常见处理

- 崩溃/升级：`adb install -r tvhome-zh-1.6.2-beta.apk`
- 拉崩溃日志：`adb logcat -d | grep -A 30 -i "FATAL EXCEPTION"`
- 开无障碍：
  ```bash
  adb shell settings put secure enabled_accessibility_services \
    com.gathin.tvhome/com.gathin.tvhome.HomeKeyService
  adb shell settings put secure accessibility_enabled 1
  ```
- 开使用情况访问（安卓 5.0+）：
  ```bash
  adb shell appops set com.gathin.tvhome GET_USAGE_STATS allow
  ```
- 一键恢复：跑 `tools/restore-tvhome.sh <电视IP>`，关权限、卸载、原厂桌面回来。

### 边界

- **只禁用，不卸载系统包。** 要卸载任何系统应用，先在群里说清楚并获得同意。
- 不改电视的账号、密码、支付相关设置。
- 不长期保留 ADB 连接，结束就 `adb disconnect <电视IP>:5555`，并提醒对方关无线调试。
- 处理结果发群里一句话：机型、原因、做了什么、现在状态。

## 备选方案

- **连不上 ZeroTier**：换蒲公英；或者对方有电脑，电脑和电视同一 Wi-Fi，电脑上装 ZeroTier，我们用电脑做内网转发（复杂，最后再考虑）。
- **完全不会操作**：微信语音一步一步指，先教开 ADB，再装组网，比远程桌面快。
- **实在不行**：让对方用 U 盘重装对应版本的包，或跑一键恢复回原厂。
