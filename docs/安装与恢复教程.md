# 电视桌面 2.1.7 安装教程

适用于小米、创维等品牌的安卓电视（Android 6.0 及以上）。装它不改系统、不删原厂应用，原厂桌面还在，只是被盖住；不想用了随时恢复。

安卓 4.0–5.1 的老电视装「老设备版」，见第七节。

**发群里的简版：**

> 电视桌面，U 盘装，不用 root。小米、创维等安卓电视都能用。
> ① 装 apk ② 设置里开无障碍「Home 键回顶」和使用情况访问「电视桌面」③ 完事
> 想恢复：设置里关掉这两个权限，再卸载。
> 详细步骤和恢复脚本在这份文档里。

## 一、准备

- U 盘一个，FAT32 格式，把 `tvhome-zh-2.1.7.apk` 拷到根目录。老电视用 `tvhome-zh-2.1.7-legacy.apk`。
- 小米 HyperOS 3 机型（例如 MiTV-MFFU0）必须用 idun 定制版，标准版装上去按 Home 还是会回原厂桌面。
- 电视能上网。热播封面和片段需要联网，第一次打开会慢一点。
- **手机不能装**：2.0.15 起在手机上打开会提示「这是电视桌面」，并可直接卸载。本应用只支持电视、投影仪和电视盒子。

## 二、安装

1. U 盘插到电视 USB 口。
2. 电视上打开「应用 → 媒体中心」（有的固件叫「高清播放器」）。
3. 找到 apk，按确定安装。
4. 提示未知来源时：设置 → 账号与安全 → 允许安装未知来源应用。

### 提示「应用未安装」或「已阻止」怎么办

按顺序排查，前两条最常见：

1. **先卸载旧版**。之前装过别人打包的版本（签名不一样），或者装过更高版本（比如 beta），覆盖安装一定失败。到「应用」里把电视桌面卸掉再装。卸载会重置桌面设置（常用应用、壁纸），重装后重新设一下。
2. **打开「未知来源」**。各品牌位置：
   - 小米 / Redmi：设置 → 账号与安全 → 允许安装未知来源的应用
   - 创维 / 酷开：设置 → 通用 → 允许安装未知来源应用；有的型号走「我的应用 → U 盘安装」
   - 海信：设置 → 更多设置 → 通用 → 商场模式
   - TCL：设置 → 系统 → 安全 → 安装未知应用
   - 华为 / 荣耀：设置 → 安全 → 更多安全设置，关掉「纯净模式」
   - 索尼：设置 → 安全和限制 → 未知来源
3. **安全软件拦截**：小米电视管家、各家的安全中心会拦第三方安装，先关掉「安装检测 / 病毒扫描」再装。
4. **系统版本不对**：安卓 5.1 及以下必须装 `-legacy` 包，装普通版会提示未安装。
5. **存储空间不足**：设置里看剩余空间，不到 200MB 先清缓存再装。
6. 都不行就用电脑装，绕开电视的安装器：见第五节。还装不上，记下**电视型号 + 安卓版本 + 提示原文**发群里。型号在 设置 → 关于 里看。

## 三、开两个权限（关键）

不装这两个，桌面能打开，但按 Home 还会回原厂桌面。

### 1. 无障碍

设置 → 无障碍（有的固件叫辅助功能）→ 找到「Home 键回顶」→ 打开。

### 2. 使用情况访问

设置 → 使用情况访问 → 找到「电视桌面」→ 允许。
有的固件在：设置 → 应用 → 特殊权限 → 使用情况访问。

这两个页面藏得比较深，找不到就用电脑开，见第五节。

## 四、怎么用

- 装完在电视的「应用」列表里会多一个「电视桌面」图标，点它打开。之后按 Home 就回这个桌面；已经在桌面时按 Home，回到第一屏。
- 海报下面有一排点，按上键进去，左右切换节目；停留 3 秒自动播该节目的片段。
- 右上角两个入口：左边 Wi-Fi，右边控制中心（开关图标）。部分遥控器的菜单/设置键直接开「桌面设置」。
- 控制中心里：输入源、壁纸、常用应用、电视设置四个圆钮；下面有蓝牙、Dock 图标数量、运行中应用与服务、一键清理、按键映射；再下面是音量、投屏、检查更新、发送反馈。
- 控制中心 → 输入源：可以直接切 HDMI1/2/3、TV、AV（接游戏机、机顶盒用）。
- 每行图标数在「桌面设置」里改：自动 / 4 / 6 / 8，点一下图标小一档，只动下面的应用区，顶上时间和右上角按钮不变。
- Dock 图标数量在控制中心里改（1–8），调小后多出来的应用自动回桌面。
- 长按桌面应用图标：新建文件夹、移入文件夹、加入常用、卸载。
- 长按 Dock 图标：加入常用、调整顺序、卸载。
- 文件夹点开是玻璃面板，里面是图标 + 名字；长按文件夹可以添加应用或解散。
- 顶栏显示当地天气，IP 自动定位，30 分钟刷新一次。天气动态壁纸在「桌面设置」里开。
- 开机时会先闪一下原厂桌面，几秒内自动盖回来，正常现象。
- 以后有新版本，电视启动时会提示更新；控制中心里有「发送反馈」，遇到问题可以直接报上来。

## 五、用电脑安装和开权限（U 盘装不上时）

电视提示「应用未安装 / 已阻止」、U 盘又找不到地方装时，用电脑的 adb 直接装，电视自己的安装器拦不到。

1. 电视：设置 → 账号与安全 → ADB 调试，打开。记下电视 IP（设置 → 关于 → 网络信息）。
2. 电脑装好 adb（platform-tools）。
3. 安装（Mac / Linux，在解压出来的目录里执行）：

```
bash install-tvhome.sh 192.168.1.23
```

Windows 双击 `install-tvhome.bat`，按提示输入电视 IP。脚本会自己找同目录里的 apk，装不上时会直接说原因（签名冲突、版本更高、系统太老、空间不足）。

4. 装完开权限，执行：

```
adb connect 电视IP:5555
adb shell appops set com.gathin.tvhome GET_USAGE_STATS allow
adb shell settings put secure enabled_accessibility_services com.gathin.tvhome/com.gathin.tvhome.HomeKeyService
adb shell settings put secure accessibility_enabled 1
```

## 六、恢复原厂

### 桌面里一键（推荐）

按遥控器菜单/设置键打开「桌面设置」→ 面板最下面「卸载桌面（恢复原厂）」→ 系统弹卸载确认 → 确定。
卸载后原厂桌面自动回来。

### 不连电脑（三步）

1. 设置 → 无障碍 → 关掉「Home 键回顶」
2. 设置 → 使用情况访问 → 关掉「电视桌面」
3. 设置 → 应用 → 应用管理 → 电视桌面 → 卸载

原厂桌面自动回来，遥控器一切照旧。

### 电脑一键恢复

- Windows：双击 `restore-tvhome.bat`，输入电视 IP。
- Mac：终端执行 `bash restore-tvhome.sh 192.168.1.23`。

电视要先打开 ADB 调试。脚本会自动关掉接管、撤销权限、卸载桌面，跑完重启电视即可。

## 七、老电视（安卓 4.x / 5.x）

安卓 6.0 以下的电视装 `tvhome-zh-2.1.7-legacy.apk`，界面和用法一样，区别在下面几点。

- **装哪个**：安卓 6.0 及以上装普通版，4.0–5.1 装老设备版。装错了系统会拒绝安装，不会把电视弄坏。
- **权限只开无障碍**：安卓 4.4 及以下没有「使用情况访问」，只开无障碍就够；5.x 两个都开，和其它机型一样。
- **海报和片段可能没有**：老电视的网络加密协议旧，取不到图时会显示静态壁纸，桌面照常用。
- **更新走老设备线路**：装好后自动检查老设备版的更新，不会覆盖成普通版。
- **反馈一样能发**：控制中心里的「发送反馈」可用，群里报问题时说一声是老电视、什么型号。
- **恢复原厂**：和第六节完全相同，卸载后原厂桌面自动回来。

## 常见问题

- **开机先进了原厂桌面**：正常，几秒内自动盖回来。
- **装完找不到「电视桌面」**：在电视的「应用」列表里，图标是一个桌面图案，名字叫「电视桌面」；有的固件要按「下」翻到第二行。实在找不到就重装一次，安装完成时直接点「打开」。
- **装的时候提示「应用未安装」/「已阻止」**：见第二节下面的排查顺序，九成是旧版签名冲突或没开未知来源。
- **按 Home 还是回原厂**：检查两个权限是不是都开了；重装过的话无障碍会掉，重新打开一次。
- **点「下载并安装」提示「此电视不支持」**：1.7.1 及以前的小米电视会这样。用这个包手动装一次 2.1.7，之后再升级就正常了。
- **海报没有图**：先确认电视联网；第一次打开要拉一遍数据，稍等一会儿。
- **遥控器失灵**：长按电视电源键重启。还不行就跑一键恢复。
- **恢复后想再装**：U 盘再装一次就行。
