# 品牌适配

桌面接管 Home 键的地方都读 `DeviceProfile`（`launcher/app/src/main/java/com/gathin/tvhome/DeviceProfile.java`）。一台电视需要知道四件事：

| 字段 | 用途 | 来源 |
|---|---|---|
| `stockHomes` | 原厂桌面包名，切到前台就把桌面盖上去 | 品牌表 + 探测（所有声明 `CATEGORY_HOME` 的包） |
| `homeClassSuffixes` | 原厂桌面里哪个页面算「首页」 | 品牌表；空 = 整个包的任何页面都算 |
| `screenSavers` | 原厂待机轮播包名 | 品牌表 + 类名以 `ScreenSaverActivity` 结尾的兜底 |
| `settingsPackages` | 厂商设置 App，系统设置入口打不开时用它 | 品牌表，按安装情况过滤 |
| `allAppsIsHome` | 遥控器的 Home 是否发 `KEYCODE_ALL_APPS` | 品牌表 |

## 新品牌怎么办

1. 先不动代码，直接装一版。未知品牌走 `generic` 档案，原厂桌面由探测得到，Home 接管应该已经能用（品牌设的 `homeClassSuffixes` 为空，原厂桌面任何页面都会触发覆盖）。
2. 装完打开一次桌面，反馈后台「错误」里会出现一条 `caps`：
   `profile=generic stockHome=[...] screensaver=[...] settings=[...] allAppsHome=false sdk=... device=厂商 型号`
   这一行就是这台电视的自述，多数情况照着它补品牌表就行。
3. 需要改行为时，在 `DeviceProfile.BRANDS` 里加一条，关键字匹配 `MANUFACTURER`/`BRAND`/`MODEL`/`DEVICE` 的小写串。只写探测拿不到的东西——能探测到的一律留空。
4. 注意：
   - `homeClassSuffixes` 收窄的是「原厂桌面的哪个页面算首页」。小米就靠 `MainActivityUserMode` 区分首页和信号源/电视页，不收窄会和原厂桌面来回抢焦点。
   - 品牌表里的设置包要真实安装才进 `settingsPackages`（用 `getPackageInfo` 判断，不用 `resolveActivity`，后者会对着没装的包返回能解析）。
   - 新品牌只加档案，不改 `HomeKeyService`/`MainActivity` 里的判断。

## 已知品牌

| 品牌 | 关键字 | 桌面 | 待机轮播 | 设置 | Home=ALL_APPS |
|---|---|---|---|---|---|
| xiaomi | xiaomi / redmi / mitv | `com.mitv.tvhome` + `MainActivityUserMode` | `com.mitv.screensaver`、`com.xiaomi.tv.gallery` | `com.xiaomi.mitv.settings` 等三个 | 是 |
| skyworth | skyworth / coocaa / tianci / 创维 / 酷开 | `com.tianci.movieplatform` + `rootpage.HomeActivity` | `com.coocaa.screensaver` | `com.skyworth.setting` | 否 |
| sony | sony / bravia | 探测 | 探测 | 系统设置 | 否 |

创维实测于 8R720_A5FP / 安卓 13（2026-10-23）：整机没有任何 `CATEGORY_HOME` 活动，Home 键由固件直接送到 `com.tianci.movieplatform/…rootpage.HomeActivity`，所以探测拿不到，只能写进档案。它的待机轮播类名是 `com.skyworth.screensaver.ui.MainActivity`，不带 `ScreenSaverActivity` 字样，因此判断规则看类名里有没有 `screensaver`，而不是固定后缀。

索尼实测于 2026-10-22：标准安卓 TV，桌面和设置都能探测到，不需要品牌字段。当天踩的坑有两个：判断小米设置包时用 `resolveActivity` 返回「已安装」，其实没装（现在统一用 `getPackageInfo`，见 `installed()`）；输入源里每个 HDMI 都被报成已连接，`TvInputs` 里按状态过滤。档案里登记 sony 只是为了反馈里能认出来。
