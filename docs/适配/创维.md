# 创维 / 酷开电视适配

实测机型：

- **8R720_A5FP**，Android 13，2026-10-23
- **85A6E**（型号代码 `8R710_A6E`），Android 13，2026-10-24

品牌识别：`Build.MANUFACTURER` / `BRAND` / `MODEL` 任一含 `skyworth`、`coocaa`、`tianci`、`创维`、`酷开` → `DeviceProfile` 的 `skyworth` 条目。

## 原厂组件

| 作用 | 组件 |
|---|---|
| 原厂桌面 | `com.tianci.movieplatform`，8R720 上是 `…rootpage.HomeActivity` |
| 原厂桌面（8R710_A6E） | 页面是 `com.coocaa.homepage.vast.HomePageActivity`，但它挂在宿主 `com.ccos.cooui.movieplatform.MainActivity` 里跑；无障碍事件报的是宿主类名 |
| 屏保 | `com.coocaa.screensaver`（类在 `com.skyworth.screensaver.ui.*`，如 `MainActivity`） |
| 系统设置 | `com.skyworth.setting` |
| 无障碍设置页 | **没有** |

## 跟别家不一样的地方

- **桌面不声明 `CATEGORY_HOME`**。系统的桌面探测一个都找不到，Home 键由固件直接派到 `com.tianci.movieplatform/…rootpage.HomeActivity`，所以只能按包名 + 类名后缀认。
- **8R710_A6E 的窗口标题不可信**。标题写着 `HomePageActivity`，无障碍事件报的却是宿主 `movieplatform.MainActivity`；以前按窗口标题匹配从来没触发过。类名后缀必须带上宿主。
- **屏保类名也不同**。小米收在 `ScreenSaverActivity`，创维在 `com.skyworth.screensaver.ui.MainActivity`，任何按类名认屏保的地方都不能写死小米那套。

## 无障碍

- `com.skyworth.setting` 里没有无障碍页。
- 标准 `ACTION_ACCESSIBILITY_SETTINGS` 在 8R710 上落到 `com.android.tv.frameworkpackagestubs` 的空壳页，点了是死路。
- 所以 `DeviceProfile` 把 `accessibilitySettings` 定为 `false`（`accessibilitySettingsPresent()` 里空壳包名也按“没有”算）。无障碍服务掉了时，桌面弹 ADB 引导（`a11y_guide_notes`），文案里给创维/酷开写了：**设置 → 关于本机 → 本机信息 → 更多信息**页按 `上上下下左右左右` 进工厂菜单开 ADB。

## 代码位置

- `DeviceProfile`：`skyworth` 品牌条目；`accessibilitySettingsPresent()`。
- `MainActivity.showAccessibilityGuide()`：无障碍页不存在时弹的引导。
- `res/values/strings.xml`、`res/values-zh/strings.xml`：`a11y_guide_notes`。

## 验证情况

- 确认过的：桌面包名/类名、屏保包名、设置包名、无障碍页缺失（两台真机探测记录）。
